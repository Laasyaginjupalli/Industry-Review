# E-commerce Industry Analysis – Predicting Shopping Cart Abandonment

## Project Overview

This project explores key challenges in the e-commerce industry, including demand forecasting, customer personalisation, and shopping cart abandonment. It focuses on identifying high-risk shopping cart abandonment using session-level behavioural data from a multi-category e-commerce retailer.

## Project Objectives

- Analyse major business challenges in the e-commerce industry.
- Review existing analytical methods and research.
- Explore customer browsing, cart, and purchase behaviour.
- Identify patterns and drop-offs throughout the customer purchasing journey.
- Propose predictive analytics approaches for identifying potential cart abandonment.

## Dataset

E-commerce Behaviour Data from a Multi-Category Store (Kaggle)

The dataset contains customer behaviour events such as product views, cart additions, purchases, timestamps, session identifiers, and product categories.

## Analytics & Methodologies

- Descriptive Analytics
- Predictive Analytics
- Customer Behaviour Analysis
- Funnel and Cart Abandonment Analysis
- Logistic Regression
- Decision Trees
- Random Forest
- XGBoost
- Survival Analysis and Sequence-Based Modelling (proposed approaches)

## Data Visualisation

Used **Tableau** to create visualisations exploring:

- Customer activity across product views, cart additions, and purchases.
- Brand-level browsing and purchasing behaviour.
- Cart additions versus completed purchases across product categories.
- Purchasing funnel drop-offs and potential abandonment patterns.
